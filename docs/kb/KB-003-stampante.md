# KB-003 La stampante di piano non stampa

Categoria: hardware o software, vedi `categorie.md`

1. Controlla sul display della stampante se ci sono inceppamenti o carta esaurita (hardware).
2. Se altri colleghi stampano regolarmente, il problema è sul tuo PC: rimuovi e reinstalla la stampante dal portale software (software).
3. Le stampe riservate restano in coda 24 ore: rilancia con il badge entro quel tempo.
