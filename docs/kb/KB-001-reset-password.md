# KB-001 Reset della password di dominio

Categoria: accessi

1. Vai su portale self-service, voce "Password dimenticata".
2. Conferma l'identità con il codice ricevuto sul telefono aziendale.
3. La nuova password deve avere almeno 12 caratteri e non può ripetere le ultime 5.
4. Dopo il reset, la VPN richiede la nuova password entro 15 minuti.

Se il telefono aziendale non è disponibile, il reset lo fa l'operatore dopo verifica dell'identità in videochiamata.
