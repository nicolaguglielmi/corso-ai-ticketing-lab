# KB-005 Il gestionale va in errore al salvataggio

Categoria: software

1. Annota il codice di errore mostrato (es. GST-409).
2. GST-409 indica che un collega sta modificando lo stesso documento: attendi qualche minuto e riprova.
3. GST-500 è un errore del server: se si ripete per più utenti, il ticket è P1.
4. Allega sempre uno screenshot senza dati dei clienti visibili.
