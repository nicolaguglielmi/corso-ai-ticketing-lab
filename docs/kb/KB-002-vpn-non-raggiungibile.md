# KB-002 VPN: il server non risponde

Categoria: rete

1. Verifica di essere connesso a internet aprendo un sito qualsiasi.
2. Se usi una rete di hotel o di un cliente, alcune porte potrebbero essere bloccate: prova dall'hotspot del telefono.
3. Riavvia il client VPN e seleziona il gateway "Roma-2" come alternativa.
4. Se nessun gateway risponde e più colleghi segnalano lo stesso problema, il ticket è P1.
